# 💻 DSA Technovation | LeetCode Series

**Learn. Solve. Practise. Grow.**

Welcome to **DSA Technovation**, the official repository for the LeetCode Series organised by **Technovation Club**.

This initiative brings club members together to practise Data Structures and Algorithms through regular LeetCode challenges. Members solve the questions shared as part of the series and contribute their solutions to this repository, making it a shared space for learning and collaboration.

## 🚀 About the Series

Through this initiative, we aim to:

- Strengthen DSA concepts and problem-solving skills.
- Build consistency through regular coding practice.
- Explore different approaches to solving problems.
- Learn and improve together.

## 📁 Repository Overview

Solutions are organised into folders named after their respective LeetCode problem numbers. The repository is updated as new questions are introduced in the series.

## 🤝 Learn Together, Grow Together

Every problem is an opportunity to learn, improve, and think differently.

**Stay consistent. Keep solving. Keep growing.**
